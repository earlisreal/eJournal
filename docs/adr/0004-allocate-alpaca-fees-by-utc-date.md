# Allocate Alpaca fees by UTC date

Alpaca legacy `FEE` activities expose exact daily CAT, REG, and TAF totals but no reliable fill or order parent; the beta Activity SSE also omits parent IDs for bulk regulatory fees. eJournal will therefore preserve each posted total while deriving Transaction allocations for the same UTC Fee Date—REG by sell notional, TAF by sell shares, and CAT by all executed shares—with debits positive, credits negative, fractional cents retained, and any floating remainder assigned to the largest allocation; live-account testing rejected New York-date matching because it missed overnight fills. Reconciliation is an atomic absolute overwrite scoped to the matching Alpaca account and environment, backfilled once and then replayed for 95 days, while unmatched, contaminated, malformed, or unknown buckets remain unapplied warnings; no raw fee table, description parser, stored order ID, or beta stream is added until measured need.
